# DIA news

Проект DIA-NEWS от Колунтаевой

Статическая страница с новостями о диабете: исследования, одобрения, препараты, устройства, доступ и цены, рынок и конференции.

## Обновление ленты

Лента обновляется автоматически раз в день (07:17 по Казахстану) через GitHub Actions: `.github/workflows/update-news.yml` запускает `scripts/update-news.mjs`.

Скрипт:
1. читает RSS-ленты о диабете (Google News на русском для России и Казахстана, Google News на английском, ScienceDaily, Medical Xpress, FDA, Breakthrough T1D);
2. отбрасывает нерелевантное и уже опубликованное;
3. если в секретах репозитория есть `ANTHROPIC_API_KEY` (или `OPENAI_API_KEY`), ИИ отбирает самые важные новости, определяет раздел и переводит заголовок и краткий пересказ на русский, английский, казахский, немецкий и испанский. Без ключа новости публикуются на языке оригинала;
4. подбирает фото к каждой новости на Unsplash (если в секретах есть `UNSPLASH_ACCESS_KEY`; запасной вариант — Pexels, `PEXELS_API_KEY`): ИИ придумывает поисковый запрос по теме новости, скрипт берёт качественный горизонтальный снимок, которого ещё нет в ленте, и указывает автора. Также собирается запасная подборка по 6 фото на каждый раздел (обновляется раз в месяц) — она используется, если у новости нет своего фото. Бесплатный режим Unsplash — 50 запросов в час, поэтому скрипт делает не больше 45 запросов за запуск, остальное доделывает при следующем. Свои фото можно поставить вручную: положите файл в `assets/photos/` и укажите `photo.url` у новости, скрипт его не заменит;
5. перезаписывает `data/news.js` (хранится до 40 материалов за последние 30 дней) и отправляет изменения в `main`, после чего Vercel пересобирает сайт.

Как добавить ключи: GitHub → Settings → Secrets and variables → Actions → New repository secret → имя `ANTHROPIC_API_KEY` (перевод) и `UNSPLASH_ACCESS_KEY` (фото, бесплатный ключ: unsplash.com/developers).
Запустить обновление вручную: вкладка Actions → Update news → Run workflow.

## Возможности

- Лента новостей с фильтром по разделам
- Пять языков интерфейса: русский, английский, казахский, немецкий и испанский

## Запуск

Сборка не нужна: откройте `index.html` в браузере.

## Структура

- `index.html` — разметка страницы
- `css/styles.css` — стили
- `data/news.js` — новости (генерируется автоматически)
- `scripts/update-news.mjs` — скрипт обновления ленты
- `js/app.js` — логика страницы
- `js/i18n.js` — тексты интерфейса на всех языках
- `js/illustrations.js`, `js/photos.js` — иллюстрации и фото
- `assets/photos/` — файлы фотографий

Материалы проекта не являются медицинской рекомендацией.
